# 🧠 Задачи для отработки навыков работы с LLM (актуальные на 2026 год)

> **Для кого:** студент, освоивший базовую теорию и практику ИИ, хочет углубиться в современный стек больших языковых моделей.  
> **Цель:** пройти путь от простых API-запросов до мультиагентных систем и продакшн-деплоя.

Все задачи расположены по принципу **«от простого к сложному»**. Выполняйте последовательно.

---

## 1. Базовое API и инженерия промптов

**Цель:** научиться управлять «личностью» модели, форматом и структурой ответа.

**Что делать:**  
Напишите скрипт для массовой обработки текстов (например, суммаризация новостей или извлечение именованных сущностей).

**Чек-лист:**
- [ ] Освойте **Zero‑shot**, **Few‑shot** и **Chain‑of‑Thought** промпты.
- [ ] Поэкспериментируйте с параметрами `temperature` и `top_p`.
- [ ] Настройте **структурированный вывод** (парсинг JSON, Markdown-таблиц).
- [ ] Реализуйте обработку ошибок, учёт токенов и лимитов API.

---

## 2. Векторные БД и семантический поиск

**Цель:** понять, как работают эмбеддинги и векторное представление текста.

**Что делать:**  
Создайте поисковую систему по своей коллекции документов (без генерации ответа, только поиск).

**Чек-лист:**
- [ ] Сгенерируйте эмбеддинги с помощью `sentence-transformers` (например, `all-MiniLM-L6-v2`).
- [ ] Посчитайте косинусное расстояние между векторами.
- [ ] Настройте семантический поиск с использованием **FAISS** или **ChromaDB**.
- [ ] Визуализируйте эмбеддинги в 2D/3D (PCA, t‑SNE).

---

## 3. Базовый RAG: чат с PDF / веб-страницей

**Цель:** собрать классический RAG-пайплайн («прочитал → нашёл → ответил»).

**Что делать:**  
Разработайте чат-бота, отвечающего на вопросы по вашим документам (PDF, Word, веб-страницы).

**Чек-лист:**
- [ ] Реализуйте умную **нарезку текста (chunking)** с перекрытием (overlap).
- [ ] Соберите индекс в векторной БД.
- [ ] Напишите логику поиска релевантных чанков (retrieval).
- [ ] Сформируйте промпт: `System + Контекст + Вопрос` → отправьте в LLM.
- [ ] Добавьте **историю диалога** (Chat Memory).

---

## 4. Продвинутый RAG (глубокое погружение)

**Цель:** улучшить качество ответов там, где простой RAG пасует (сложные, многозначные запросы).

**Что делать:**  
Возьмите базового RAG-бота и примените современные техники улучшения (на объёмных данных – 800k+ документов).

**Чек-лист:**
- [ ] Внедрите **Query Rewriting** (переписывание запроса с помощью LLM) и **HyDE** (генерация гипотетического ответа для поиска).
- [ ] Попробуйте **Multi‑Query Retrieval** (генерация нескольких вариантов запроса).
- [ ] Добавьте **Reranking** – повторное ранжирование найденных чанков более точной моделью (например, `cross-encoder`).
- [ ] Внедрите **LLM‑as‑a‑Judge** для оценки качества ответов (метрики: MRR, nDCG, Faithfulness).
- [ ] Используйте фреймворк **DSPy** для автоматической оптимизации промптов всего пайплайна.

---

## 5. Интеграция: Tool Calling / Function Calling

**Цель:** научить LLM взаимодействовать с внешним миром (API, калькулятор, базы данных).

**Что делать:**  
Сделайте агента, который умеет выполнять действия по запросу (например, получать курс валют, бронировать билеты, отправлять письма).

**Чек-лист:**
- [ ] Опишите функции в формате JSON Schema для вызова внешних API.
- [ ] Реализуйте **агентский цикл**: LLM → решение вызвать функцию → выполнение → возврат результата в LLM.
- [ ] Соберите цепочку через `LangGraph` или `LangChain`.
- [ ] Потренируйтесь на конкретной задаче (например, **Flight Booking Agent**).

---

## 6. Multi‑Agent Systems (мультиагентные системы) и MCP

**Цель:** создать систему из нескольких специализированных ИИ-агентов, которые взаимодействуют друг с другом (**самый горячий тренд 2025–2026**).

**Что делать:**  
Соберите команду агентов (например, *Исследователь → Кодер → Рецензент*) для решения сложной задачи, требующей разных компетенций.

**Чек-лист:**
- [ ] Спроектируйте **граф состояний** в `LangGraph`.
- [ ] Настройте **маршрутизатор (Router)** – один агент направляет запрос другому.
- [ ] Реализуйте **Handoff** (передачу контекста и состояния между агентами).
- [ ] Изучите **Model Context Protocol (MCP)** – новый стандарт для подключения инструментов к агентам.

---

## 7. Сквозной MLOps: Fine‑Tuning + деплой

**Цель:** дойти до продакшна – дообучить открытую модель и развернуть её как сервис.

**Что делать:**  
Возьмите базовую модель (Llama 3 / Qwen / Mistral) и дообучите на своём датасете (например, генерация SQL-запросов или ответов в вашем стиле). Затем заверните в микросервис.

**Чек-лист:**
- [ ] Подготовьте датасет в формате `{"instruction": "...", "output": "..."}`.
- [ ] Проведите **QLoRA** (эффективное дообучение) на Colab или локально (GPU 8–16 ГБ).
- [ ] Запустите эксперименты с логированием в **MLflow** или **Weights & Biases**.
- [ ] Соберите **FastAPI**-сервис, загружающий дообученную модель.
- [ ] Запакуйте в **Docker** и разверните на платформе (Modal, HuggingFace, или свой VPS).

## 🚀 Рекомендуемый стартовый маршрут

1. Установите **Ollama** и запустите локально `llama3` или `qwen`.
2. Выполните **Задачу №1** (API + промпты).
3. Сразу переходите к **Задаче №3** (базовый RAG: загрузите PDF и задайте 5 вопросов).
4. Как только RAG заработает – добавляйте **Tool Calling** (Задача №5).
5. Затем осваивайте **мультиагентов** (Задача №6) – это даст вам стек, который ищут в 90% вакансий AI‑инженера.

---

> **Итог:** если закроете задачи 3, 5 и 6 – вы будете уверенно владеть современным LLM‑стеком и сможете претендовать на позицию Junior AI Engineer / ML Developer. Удачи! 🍀
